# Tauchlog

Logbuch für Taucher als Web-App fürs Handy: Tauchgänge, Statistik, Ausrüstungs-Checkliste mit Wartung, Brevets und Weltkarte mit bekannten Tauchplätzen (OpenStreetMap).

Alle Daten bleiben im Browser des Geräts. Backup als JSON-Datei über „Backup“ im Logbuch.

Tauchlog berechnet keine Nullzeiten oder Dekompression. Dafür gilt immer der Tauchcomputer.
